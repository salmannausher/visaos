# Solo-Founder AI Workflow

ChatGPT: strategic research, SEO map, keyword classification, public-source research, evidence matrices, article briefs, content drafts, analytics explanations. Codex/Claude: architecture, Astro implementation, tests, CI, performance/SEO fixes, code review and independent content critique. Founder: priorities, source checking, release acceptance, publishing, account access, and business decisions.

Use prompts as roles, not necessarily paid agents. No background API automation or unsupervised publication by default. Avoid recurring paid APIs. Log task results and update `CURRENT_STATUS.md` after changes. Be explicit about work tested vs. merely planned.

Before a new coding task: read AGENTS.md and docs; inspect repo; write a small implementation plan; change only requested scope; run checks; summarize files, tests, risks, and follow-ups.
