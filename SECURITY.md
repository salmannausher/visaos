# Security Policy

VisaOS is developed in a public repository. Do not include applicant data, credentials, account screenshots, private analytics exports, or other sensitive material in an issue, pull request, commit, or build log.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting flow for this repository when it is available. If that option is unavailable, contact the repository owner through an existing private channel. Do not open a public issue containing exploit details, personal data, or credentials.

If a credential may have been exposed, revoke or rotate it first. Repository-history cleanup is not a substitute for revocation.

## Supported version

Security fixes apply to the current default branch. Dependency updates must pass the repository, build, content, and generated-site validation gates before merge.
